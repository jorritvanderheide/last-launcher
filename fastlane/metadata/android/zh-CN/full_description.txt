Last Launcher 是一款为速度与简洁而打造的极简纯文字 Android 启动器。没有图标，没有小组件，没有杂乱，你的应用只是一行行朴素的文字标签。

功能：
* 纯文字主屏幕，可固定应用快捷方式
* 快速的应用抽屉，支持即时搜索
* 任务列表，支持搜索、重新排序和滑动移除
* 长按即可就地操作：重命名、固定、隐藏
* 仅搜索模式，适合以键盘优先的方式启动应用
* 跟随系统/浅色/深色主题，支持纯黑 AMOLED
* 扩展主题，带有 CRT 扫描线效果和等宽字体
* 隐藏你不想看到的应用
* 搜索只匹配到一个应用时自动启动
* 全屏模式，隐藏状态栏和导航栏
* 提供英文、荷兰文

Last Launcher 免费、开源（EUPL-1.2），不含广告、跟踪或遥测。你的数据保存在你的设备上，除非你通过其他应用同步任务。

---
无障碍服务披露：
Last Launcher 使用 Android AccessibilityService API 来实现可选的“双击休眠”手势。

我们不会通过 AccessibilityService API 收集、存储或传输任何个人或敏感的用户数据，任何信息都不会被共享或发送到你的设备之外。
